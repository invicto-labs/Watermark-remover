BEFORE YOU DOWNLOAD

A few practical details.

Do my PDFs leave my computer?

PDF processing happens locally in the Windows app.

An internet connection is required to verify credits and document access. Payment verification uses an online service, installation IDs, SHA-256 document fingerprints and order/payment references. It does not upload your PDF contents.

Any custom-support sample is shared only if you choose to send it.

What counts as one document?

One distinct original PDF, regardless of page count. Reopening a byte-identical PDF, including a renamed copy, uses no additional credit.

A modified PDF may count as another document.

Can ClearPage remove every watermark?

No. Supported presets depend on the document layout. Marks overlapping original text can be difficult to remove.

Review names, numbers, signatures and fine details before accepting a result.

What is in this Windows download?

ClearPage opens as its own Windows desktop application, with no browser tab for document work. Secure payment checkout and release links may open in your default browser. Microsoft Edge WebView2 Runtime is required; if it is missing, install it from the official Microsoft website. The download button always follows the latest published stable release.

The Standard preview includes the standard cleanup workflow. Optional LaMa AI reconstruction and neural OCR model files are not included. Payment setup is incomplete, so this preview cannot collect money.

What is the refund policy?

Custom cleanup has a two-hour delivery-or-refund promise after we receive your complete requirements and any requested sample. If we cannot deliver the agreed result in that time, we refund the price paid for the affected service.

Email sales@zynape.com with your payment reference. No real payments are accepted in this preview.
